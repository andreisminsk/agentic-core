# python

The project targets Python 3.9+. On this machine no `python` exists; the
working interpreter is `python3.13`. Prefer `bash .sh/which-python.sh`
to re-resolve it if the environment changes.

Run tests, examples, and any script with `python3.13` (e.g.
`python3.13 -m pytest tests/ -q`). Never invoke bare `python`.
